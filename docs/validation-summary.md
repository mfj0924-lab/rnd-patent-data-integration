# 汇总验证与公开边界

## 原课程任务结果

- 研发投入主表：24,078 条记录。
- 专利年度文件：2010—2021 年，共 48,468 条专利记录。
- 按“证券代码 + 年份”复合键成功匹配：21,605 条。
- 匹配率：89.7292%。
- 12 年专利数量汇总：7,314,834。

以上数字来自原任务交付前的行数、匹配状态与求和核验。公开仓库中的合成样本只用于复现两类表头识别、证券代码清洗、年份标准化和左连接流程，不用于复现真实统计结果。

## 为什么不上传真实 Excel 和课程截图

原始与合并后的公司级数据包含证券代码、公司简称、研发金额和专利数量，其再分发授权未得到确认。课程截图还包含本机路径、姓名/学号或第三方表格内容。因此公开仓库只保留：

1. 可复用的数据整合代码；
2. 不含真实公司的合成小样本；
3. 不包含公司级明细的汇总验证数字；
4. 明确的数据与结论边界。

这种处理不会牺牲项目能力证据：面试官仍可运行样例、检查复合键和异常格式逻辑，并核对输出字段；同时避免把第三方数据当作本人可自由公开的资产。
